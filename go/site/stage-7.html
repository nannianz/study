JS 对照重点

JS 对照

依赖注入 vs JS 手动 new / 前端 IoC 容器（如 Angular DI 的影子）。

第一课 · uber/fx 依赖注入 讲义就绪 · 未开课

读懂 boot.go 里的 container.Add / fx.Invoke。

// smb boot.go 的骨架（简化）
container := cmds.NewRoot(...)
container.Add(
    config.Module(),      // 每个模块声明自己提供什么
    pgsql.Module(),
    controller.Module(),
)
container.Invoke(func(eng *gin.Engine, cs []controller.Controller) {
    // fx 自动按类型把依赖注进来 → 注册路由 → 启动
})

fx 核心两件事：① 扫描所有 Module 声明的「提供者」（构造函数）；② 按参数类型自动连线组装，缺依赖/循环依赖启动时报错。相当于一个自动 new 的总装车间。

JS 对照

≈ Angular 的 DI 容器（按 token 注入）或 NestJS 的 Provider。没有 DI 时你得在 main 里手动 new Repo → new Service(repo) → new Controller(service) 一层层穿针引线（net_scan 就是手动的，所以它好读；smb 服务多，用 fx 省心）。

back 对照

gobase 的 modules/quick-start/di.go 是 fx 封装的启动框架；smb 与 svac 的 boot.go 都靠它。读法：先看每个包的 di.go（Module() 里 Provide 了什么），再回 boot.go 看总装清单。

第二课 · 泛型仓储精读 讲义就绪 · 未开课

gobase/modules/pgsql/repository.go 逐方法拆解。

阶段 3 认过 PostgreSqlRepo[T] 的脸，这节读实现：Insert 怎么落到 gorm、FindByWhere 的 where 参数为什么是 ...interface{}（可变参数 + 任意类型占位）、事务怎么在泛型层封装。精读目标：service 层一行 siteRepo.FindByWhere(ctx, "org_id = ?", orgID) 背后发生了什么全部说得清。

JS 对照

≈ 通用的 Repository<T> 基类（TypeORM 的 BaseRepository 同思路），Go 用泛型 + 接口组合达成。

第三课 · casbin 权限与 MQTT 讲义就绪 · 未开课

casbin：RBAC 的落地

enforcer.Enforce(userID, resource, action)   // 用户能不能干这件事

casbin 把「谁-能对-什么-做什么」抽象成策略模型（model.conf）+ 策略表；smb 的 security/ 目录是它的封装层（登录、token、中间件一整套）。前端同事熟悉的「菜单权限」在后端就是这一行判断。

MQTT：设备消息总线

smb 管理的 AC 设备跑在 MQTT 上——设备的 HTTP API 被「HTTP-over-MQTT」代理（apiac 路由组）：前端请求 → smb 转成 MQTT 消息发设备 → 设备回消息 → smb 转回 HTTP 响应。并发课的 channel 在这里全是实战。

JS 对照

casbin 有 JS 版（同一套策略文件前后端通用）；MQTT ≈ WebSocket 的发布/订阅版（topic 就是频道）。

第四课 · 毕业精读：Site 更新全链路 讲义就绪 · 未开课

毕业设计 · 无代码，纯阅读

把阶段 1~6 学的全部语法对号入座，沿一条 PATCH /api/v1/sites/{site_id} 请求走完全程：

  1. restserver.go：路由组怎么建、UpdateSite 怎么挂上去
  2. sitecontroller.go：g.Param / BindJSON / logger.Errorf / RetJSON（阶段 1~3 的语法全家桶）
  3. siteservice.go：UpdateSiteRequest 的指针字段 PATCH 语义、事务、casbin 检查、泛型仓储调用
  4. entity/site.go：双 tag 落到 PostgreSQL 的最终形态
  5. 反向验证：合上代码，画出这条请求的分层流转图

验收标准：任意挑一层你能讲清「它做什么、为什么在这层、参数从哪来到哪去」——达到「能改需求」水平，全部课程结业 🎓
