JS 对照重点

JS 对照

ES modules vs Go packages：import 路径 = 仓库路径；大写开头 = export（≈ JS 的 export 关键字被命名规范取代）。

go get ≈ npm install；go.mod+go.sum ≈ package.json+lock。

go test vs vitest/jest：无断言库依赖（if got != want { t.Errorf(...) }）、表驱动测试是官方推荐范式。

gofmt/go vet ≈ prettier/eslint，但内置零配置。

第一课 · 包、模块与文件 讲义就绪 · 未开课

覆盖 ch31/33（包/Modules）+ ch27（文件处理）。练习落在 code/11-packages/。

1. 大写导出，小写私有

package utils

func Hash(s string) string { ... }   // 大写开头 → 其他包可用（≈ export）
func hash(s string) string { ... }   // 小写开头 → 仅本包可见

常量、类型、结构体字段、方法全部同规则。没有 export 关键字——命名即可见性。

2. import 路径与 go mod

import (
    "fmt"                       // 标准库
    "gostudy/pkg/utils"         // 本模块内：模块名 + 相对路径
    "github.com/gin-gonic/gin"  // 第三方：仓库路径
)
go get github.com/x/y@v1.2.3   // 加依赖 ≈ npm install pkg@版本
go mod tidy                    // 按实际 import 清理/补齐依赖表

internal/ 魔法目录：路径里带 internal 的包只有其父目录树内能 import，外部强行 import 直接编译报错——编译器强制的私有边界。back 的 smb_server/internal 就靠它锁住 controller/service 不被外部引用。

3. 文件读写三件套

data, err := os.ReadFile("config.json")      // 一口读
err = os.WriteFile("out.txt", data, 0644)    // 一口写

f, _ := os.Open("big.log")                   // 大文件：逐行
scanner := bufio.NewScanner(f)
for scanner.Scan() {
    line := scanner.Text()
}

1. 测试文件与函数

func TestDeviceDiscount(t *testing.T) {     // Test 前缀 + *testing.T 参数
    d := Device{Name: "AP", Price: 100}
    got := d.Discount(0.8)
    if got != 80 {
        t.Errorf("Discount(0.8) = %v, want 80", got)   // 报错不中断
    }
}
go test ./...           # 跑全部测试
go test -run TestDevice # 只跑一个
go test -v              # 显示每个用例

2. 表驱动测试（官方范式）

func TestDiscount(t *testing.T) {
    tests := []struct {
        name  string
        price float64
        ratio float64
        want  float64
    }{
        {"正常8折", 100, 0.8, 80},
        {"零价格", 0, 0.8, 0},
        {"免费", 100, 0, 0},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            d := Device{Price: tt.price}
            if got := d.Discount(tt.ratio); got != tt.want {
                t.Errorf("%s: got %v want %v", tt.name, got, tt.want)
            }
        })
    }
}

3. JS 对照

JS 对照

vitest 的 expect(got).toBe(want) 好写，但那是框架能力；Go testing 包零依赖、零断言库——if + t.Errorf 就是全部。表驱动 ≈ test.each([...])：用例数据与断言逻辑分离，加用例只加一行。t.Run ≈ describe/it 层级。
