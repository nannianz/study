Go 从零学习 · 总览

学员背景：熟悉 JavaScript（ES6+、async/await、npm 生态），零 Go 基础。不定周期，按阶段推进。

学习目标

① 读懂 smb
能精读 D:\project\back\smb 一个完整功能的全链路（路由 → controller → service → repo → entity），达到能改需求的水平。
② 独立开发
能独立写一个 gin + gorm 的完整 CRUD 后台服务（net_scan 风格）。

教学三原则

  • 每个新概念必须给 JS 对照：相同点 / 不同点 / 从 JS 转 Go 的易踩坑。
  • 概念讲完必须对照 back 真实代码：从 D:\project\back 摘真实代码举例，优先级 net_scan → smb → gobase。
  • 练习代码必须跑通才算完成：go/code/<编号-主题>/main.go，go run . 输出符合预期才算完成。
